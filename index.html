Поддерживаются настоящие карты Minecraft:
• Bedrock / PE — файл .mcworld (или ZIP папки мира с db/)
• Java Edition — ZIP папки мира (с region/*.mca) или сами файлы .mca (можно выбрать несколько вместе с level.dat)
• Резервная копия этого клона — .mcpeweb
