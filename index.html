Сетевая игра
Как играть вместе: тот, у кого мир, заходит в него, жмёт Пауза → «Открыть для друзей» и отправляет код или ссылку. Второй игрок открывает ссылку (или вводит код здесь) — и вы в одном мире. Работает через интернет, без настройки роутера: связь идёт через бесплатный публичный MQTT-сервер.
Импорт карты
Поддерживаются настоящие карты Minecraft:
• Bedrock / PE — файл .mcworld (или ZIP папки мира с db/)
• Java Edition — ZIP папки мира (с region/*.mca) или сами файлы .mca (можно выбрать несколько вместе с level.dat)
• Резервная копия этого клона — .mcpeweb

Карта сохраняется в хранилище браузера. Высота 0–255, неизвестные блоки заменяются похожими.
